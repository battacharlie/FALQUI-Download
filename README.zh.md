## 2.0 版本及对 1.x 版本的致歉

我们向下载了最初 Android 版本（1.x）的用户致歉：这些版本经常无法运行或无法更新。原因在于应用的数字签名：每个 1.x 版本都使用了不同的密钥签名，因此 Android 不接受它作为已安装版本的更新。1.x 版本已被撤回。

从 2.0 版本起，所有版本都使用相同的签名。**如果你安装过之前的版本，请先卸载一次**，然后安装 2.0：以后的更新都可以直接覆盖安装。
